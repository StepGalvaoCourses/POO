# Programação Orientada a Objetos (POO) - Java ☕

Bem-vindo ao repositório da disciplina de **Programação Orientada a Objetos**. Este espaço será o nosso site central para informações sobre a disciplina, como o cronograma e a distribuição de materiais teóricos, enunciados de práticas e seus gabaritos.

## 🎯 Objetivos da Disciplina
- Compreender os conceitos fundamentais de POO (Classes, Objetos, Atributos e Métodos).
- Dominar os pilares da orientação a objetos: **Encapsulamento, Herança, Polimorfismo e Abstração**.
- Desenvolver um projeto final utilizando o ecossistema **Spring Boot**.
